## 📖 简介

小梦（XIAOMENG）是一款专为 QQ 机器人设计的**娱乐 + 群管**插件。开箱即用，轻量稳定，把繁琐的群务交给小梦，把时间还给群友。

> 🔗 **官网**：[https://xiaomengweb.pages.dev/](https://xiaomengweb.pages.dev/)
>
> ☕ **赞助支持**：[爱发电 · 请我喝杯奶茶](https://afdian.com/a/awanxm)


---

## ✨ 核心功能

| 模块 | 说明 |
| :--- | :--- |
| 🎮 **娱乐互动** | 签到、答题、点歌、表情包、小游戏……一键开启活跃气氛 |
| 🛡️ **群务管理** | 入群审核、关键词检测、警告与禁言、自动踢人，规则清晰 |
| ⚔️ **PK 对战** | 玩家之间可进行实时战斗 |
| 🌾 **农场系统** | 种植、偷菜、浇水、收获，丰富的模拟经营玩法 |
| 📈 **股票系统** | 实时股票交易，体验资本市场的魅力 |
| 🎣 **钓鱼系统** | 多种鱼类，图鉴收集，休闲娱乐 |

> 完整功能列表请查看 [功能文档](https://github.com/HANG-XM/XIAOMENG/wiki)

## 🚀 快速开始

### 1. 下载插件
从 [Releases 页面](https://github.com/HANG-XM/XIAOMENG/releases) 下载最新版 `XIAOMENG.zip`，解压得到 `小梦.dll`。

### 2. 放入框架
将 `小梦.dll` 放入机器人框架的**插件目录**，重启框架即可自动加载。

### 3. 召唤菜单
在 QQ 群中发送：小梦菜单

### 4. 如需绑定 QQ账号
请先发送：绑定

## 📁 框架适配说明

不同框架对 DLL 文件名有特殊要求，请按需修改：

| 框架 | 文件名要求 |
| :--- | :--- |
| **梦幻框架** | `小梦.dll` → `cc.hanghang.xiaomeng.dll` |
